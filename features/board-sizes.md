# Beyond the Classic 3×3 Board

**Choose the challenge that fits your style.**

<!-- TODO: replace with real 3x3 / 4x4 / 5x5 board size screenshot -->

Classic Tic Tac Toe is fun, but it can become predictable. This game introduces larger boards for deeper thinking, longer matches, and more strategic gameplay. Players can freely choose between **3×3, 4×4, and 5×5**. Larger boards create new winning possibilities and significantly increase replay value for experienced players.
