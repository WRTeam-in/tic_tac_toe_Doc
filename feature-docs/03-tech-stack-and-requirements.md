# Tech Stack & Requirements

## Built With

Tic Tac Toe is built using modern technologies that provide excellent performance, real-time multiplayer capabilities, and simplified deployment.

**Core technologies:**
- Flutter
- Firebase Authentication
- Firebase Realtime Database
- Firebase Storage
- Google Play Billing
- Apple In-App Purchases
- Google AdMob
- Unity Ads

## Server Requirements

Unlike traditional applications, Tic Tac Toe does **not** require a dedicated backend server or hosting environment.

**Required:**
- Firebase Project
- Firebase Blaze (Pay-as-you-go) plan

Firebase handles user authentication, real-time multiplayer communication, player data, cloud storage, and application services — deployment is simple and maintenance overhead is minimal.

## Development Environment

Recommended tools for development, customization, and deployment:

- Flutter SDK
- Android Studio or Visual Studio Code
- Xcode (for iOS builds)
- Firebase Console
- Google Play Console
- Apple App Store Connect

## Tech Stack Breakdown

- **Frontend (Flutter)** — develop once, deploy to Android and iOS from a single codebase, for consistent performance and easier maintenance.
- **Backend Services (Firebase)** — serverless cloud platform powering authentication, multiplayer communication, cloud storage, and player management without traditional backend infrastructure.
- **Authentication (Firebase Authentication)** — Google Sign-In, Apple Sign-In, Email Authentication, and Guest Login.
- **Database (Firebase Realtime Database)** — fast, real-time synchronization for multiplayer gameplay, matchmaking, player rankings, and online game sessions.
- **Storage (Firebase Storage)** — securely stores player profile images and other media assets.

## Monetization

- **In-App Purchases** — Google Play Billing, Apple In-App Purchases.
- **Advertising** — Google AdMob, Unity Ads.

## Payments

Native store payments via Google Play and Apple, giving players a secure, familiar purchase experience.

**Available purchases:**
- **Coin Packages** — virtual coins for competitive online matches and unlocking in-game content.
- **Remove Ads** — one-time purchase that permanently removes advertisements.
